# Export manifest — v2.0.0-preview

- Date: 2026-09-28
- Base: `website-source-export.zip` (2026-09-28), imported unchanged as commit `2f22f43`
- Package: portable Node.js static-site repository, one optional serverless function, and the generated `dist/`

## Layout

```text
.
├── .env.example            documentation only; not loaded automatically
├── .nvmrc                  Node 22
├── .openai/hosting.json    inert metadata from the base; not read by anything
├── README.md · PORTABILITY.md · EXPORT_MANIFEST.md
├── package.json            no dependencies; scripts: build, build:release, check, check:release, dev, start
├── build.mjs · build/      generator (data, components, layout, pages)
├── content/                portfolio.json (untouched record), site.json, photos.json, media.json, map-scope.json
├── src/css/ · src/js/      styles (8 ordered layers) and ES modules (site, film, develop-gl)
├── api/enquiry.js          POST /api/enquiry
├── assets/                 fonts + OFL licences, vendor/ GSAP + ScrollTrigger, media/ (print twins, og.jpg)
├── tools/                  optional: build-media.py, build-map.mjs (+ its own package.json), capture-og.mjs, og-card.html
├── server.mjs · verify.mjs local server (static + API) and release gate
├── vercel.json             generated by build.mjs
├── docs/                   DECISIONS.md, CONTENT-REQUIRED.md, DEPLOYMENT.md, v1/ (base records and v1 sources)
└── dist/                   generated: 45 routes + 404 + 7 redirect pages, sitemap, robots, llms.txt, _headers, _redirects
```

## Inventory

- Runtime: Node.js ≥ 22.9 (tested on 24.16.0). npm dependencies: none. `tools/node_modules` is only for the optional map builder and is not committed.
- Browser libraries, vendored: GSAP 3 and ScrollTrigger.
- Fonts, self-hosted under the SIL Open Font License: Anek Latin, Newsreader, Martian Mono.
- Images: the owner's own photographs only, processed into colour (AVIF/WebP) and dithered "ink" twins.
- Environment variables (all optional): `SITE_ORIGIN`, `RESEND_API_KEY`, `ENQUIRY_TO`, `ENQUIRY_FROM`, `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY`, `RELEASE`.

## Exclusions

Secrets, `.env`, `node_modules`, `.git`, prior archives and staging folders. The CV, career workbook and any client documents are not published. Referees' details and date of birth are never rendered, and `verify.mjs` checks for them.
