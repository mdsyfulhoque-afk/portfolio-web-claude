# Deployment

## Vercel (reference host)

1. Import the repository. `vercel.json` already sets the build command (`npm run build`), the output directory (`dist`), clean URLs, trailing slashes, redirects, security headers and cache rules.
2. Set environment variables (Project → Settings → Environment Variables). See `.env.example`:
   - `SITE_ORIGIN`: the production URL. If unset, Vercel's production domain is used.
   - `RESEND_API_KEY`, `ENQUIRY_TO`, `ENQUIRY_FROM`: enable server-side sending of briefs.
   - `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY`: optional spam check.
   - `RELEASE=1`: makes the build fail on photos without recorded consent. Recommended for Production once `docs/CONTENT-REQUIRED.md` items 1–2 are resolved.
3. Deploy. `api/enquiry.js` is picked up as a Node.js function automatically.

`vercel.json` is regenerated by every build from the same definitions as `_headers`, so edit the header, redirect and cache lists in `build.mjs` rather than editing it by hand.

## Netlify or Cloudflare Pages

- Build command: `npm run build`. Publish directory: `dist`.
- `dist/_headers` and `dist/_redirects` are read natively.
- For the form, mount `handle` from `api/enquiry.js`:
  - Netlify: create `netlify/functions/enquiry.mjs` containing `import { handle } from '../../api/enquiry.js'; export default req => handle(req); export const config = { path: '/api/enquiry' };`.
  - Cloudflare: in `functions/api/enquiry.js`, `export const onRequestPost = ({ request, env }) => handle(request, env)`.
- If no function is mounted, the form falls back to the visitor's email or WhatsApp. Nothing breaks.

## Any static host or your own server

- Publish `dist/` with directory-index support and `404.html` as the error page.
- Apply the headers in `dist/_headers`.
- `node server.mjs` is a working reference server: it serves static files and mounts the API.

## Checks before every deploy

```sh
npm run build && npm run check                 # preview
RELEASE=1 SITE_ORIGIN=https://… npm run check:release   # production
```

## Regenerating assets (optional)

- Photos → print twins: `python tools/build-media.py`. Needs Pillow. Outputs to `assets/media/` and `content/media.json`.
- Scope map: `cd tools && npm ci && npm run map`.
- Social card: `npm run build && node tools/capture-og.mjs`. Needs a local Chrome, Chromium or Edge; set `CHROME_PATH` if it isn't found.

Outputs are committed, so none of these tools is needed to build or deploy.

## Rollback

Redeploy a previous deployment from the host's dashboard. Alternatively, check out an earlier commit and run `npm run build && npm run check`. `docs/v1/` and the first commit hold the untouched base.
