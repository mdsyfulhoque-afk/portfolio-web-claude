# Secrets

Version 1.0.0 · 16 September 2026

The application requires no environment secrets. Do not put Sites source repository write credentials in files, Git URLs, Git configuration or archives. Short-lived publication credentials are used only for the authenticated push. The public business email and phone are content, not secrets.

Do not publish the original career research workbook, analysis DOCX, full CV, or any future client bid documents. The built `dist` contains only the intentionally selected public content and a concise professional profile.
